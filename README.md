# 🏎️ Los años dorados — Michael Schumacher × Ferrari (2000–2004)

### Un recorrido interactivo por una de las eras más dominantes de la Fórmula 1

[🌐 Ver proyecto en vivo](https://schumacher-ferrari.vercel.app/) · [💻 Repositorio](https://github.com/fededelcuadro/Schumacher-Ferrari)

## 📖 Sobre el proyecto

**Los años dorados** es un proyecto de **visualización de datos y narrativa interactiva (scrollytelling)** que explora la etapa de Michael Schumacher en Ferrari entre **2000 y 2004**, período en el que conquistó cinco campeonatos mundiales de pilotos consecutivos.

La página combina información histórica, estadísticas por temporada, gráficos interactivos y contenido multimedia para contar cómo se construyó el dominio de Ferrari y cuál fue su legado en la Fórmula 1.

Se desarrolló como **trabajo final de la materia Visualización de Datos** de la **Universidad Torcuato Di Tella (2026)**.

## ✨ Características principales

- **Narrativa por capítulos:** recorrido por cada temporada de 2000 a 2004, desde el regreso de Ferrari al campeonato de pilotos hasta el séptimo título de Schumacher.
- **Estadísticas por temporada:** victorias, puntos, pole positions, podios, abandonos y resultados del campeonato de constructores.
- **Visualizaciones interactivas:** gráficos integrados de Flourish para comparar resultados y observar la evolución del dominio de Ferrari.
- **Exploración geográfica:** mapa de los Grandes Premios ganados durante el período.
- **Contenido multimedia:** fotografías, una representación 3D del Ferrari F2001 y una experiencia de audio vinculada al F2004.
- **Diseño narrativo:** presentación visual construida alrededor del desplazamiento por la página (*scrollytelling*).

## 🛠️ Tecnologías y recursos

- **HTML, CSS y JavaScript:** estructura, estilos e interacciones del sitio.
- **Flourish:** visualizaciones de datos integradas.
- **Sketchfab:** visualización 3D integrada del Ferrari F2001.
- **Vercel:** publicación del sitio web.

## 🚀 Cómo visualizarlo

**Opción 1 — Versión online:**

Entrá a **https://schumacher-ferrari.vercel.app/** para explorar el proyecto desde el navegador.

**Opción 2 — Versión local:**

1. Cloná el repositorio:

   ```bash
   git clone https://github.com/fededelcuadro/Schumacher-Ferrari.git
   ```
2. Abrí la carpeta descargada.
3. Abrí `index.html` en tu navegador.

> Algunas visualizaciones y recursos multimedia se cargan desde servicios externos, por lo que requieren conexión a Internet.
